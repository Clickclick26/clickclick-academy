Add or edit a course

Fill the form, then download the two files it produces and drop them into the clickclick-academy folder (replacing the old ones). Then deploy as usual.

This page is a local tool, not part of the live app. It doesn't save anything by itself — you still download the updated courses.json / packs.json and push them yourself. It has no password, so don't link it from anywhere public; treat the URL like a backstage door. It also can't host video — put the real lesson (Loom, Google Drive, YouTube unlisted, Lark Docs…) behind the "Link" field below, and the course card will open it.
